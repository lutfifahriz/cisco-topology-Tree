# Tree Topology Simulation

Simulasi jaringan menggunakan topologi Tree pada Cisco Packet Tracer.

## Deskripsi
Project ini menggunakan:
- 1 Server
- 4 Switch
- 5 PC

Server digunakan sebagai DHCP Server dan seluruh PC menggunakan DHCP Client.

## Konfigurasi
- DHCP Server
- Hierarchical Network Structure
- Automatic IP Addressing

## Implementasi
Topologi Tree cocok digunakan untuk jaringan dengan struktur bertingkat seperti sekolah atau perusahaan.

## Kelebihan
- Mudah dikembangkan
- Struktur jaringan lebih terorganisir
- Mendukung banyak perangkat

## Kekurangan
- Bergantung pada jalur utama
- Konfigurasi lebih kompleks dibanding star
